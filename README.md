## Deskripsi Proyek

Proyek ini merupakan purwarupa aplikasi web **Voucher Kas Keluar** untuk membantu pencatatan transaksi pengeluaran kas dan penyusunan jurnal debit serta kredit.

Fitur aplikasi meliputi:
- Formulir entri voucher kas keluar.
- Rincian akun dan nominal debit-kredit.
- Perhitungan total debit dan kredit secara otomatis.
- Indikator keseimbangan jurnal.
- Konfirmasi dan penyimpanan voucher.

## Teknologi yang Digunakan

- HTML, CSS, dan JavaScript untuk aplikasi web.
- Supabase untuk basis data.
- SQL untuk struktur tabel, trigger, validasi, dan audit trail.
- Gemini untuk membantu pembuatan purwarupa aplikasi.
- NotebookLM untuk membantu evaluasi aturan bisnis.

## Bukti Pengujian

Bukti pengujian yang dilampirkan meliputi:
1. Tampilan aplikasi Voucher Kas Keluar.
2. Pemeriksaan keseimbangan debit dan kredit.
3. Ringkasan transaksi sebelum penyimpanan.
4. Konfirmasi keberhasilan penyimpanan voucher.
5. Bukti data jurnal pada Supabase, yaitu tabel `journal_headers` dan `journal_lines`.
